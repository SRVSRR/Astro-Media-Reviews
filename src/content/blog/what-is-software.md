Software is the product that software professionals build and support over the long term. It's more than just code — it's a complete system of programs, data, and documentation working together.

## **What Makes Up Software?**

Software consists of three core components:

1. **Programs** — Instructions that execute to deliver features, functions, and performance
2. **Data Structures** — Enable storage and manipulation of information
3. **Documentation** — Describes how the program operates and how to use it

## **Types of Software Products**

There are two main categories of software products:

- **Generic Products** — Stand-alone systems sold to any customer. The developer owns the specification and license (e.g., MS Office, CAD software)
- **Customized Products** — Built for a specific customer's needs. The customer typically owns the specification and license (e.g., air traffic control systems, embedded control systems)

## **The Reality of Software Costs**

Software costs more to maintain than to develop. For long-lived systems, maintenance costs can be several times higher than initial development costs.

## **Key Characteristics of Software**

Unlike physical products, software has unique properties:

- It's **developed and engineered**, not manufactured — this creates different quality challenges
- It doesn't "wear out" but **deteriorates through change**
- It follows a "bathtub curve" pattern for defects

## **Categories of Software Applications**

1. **System Software** — Compilers, editors, and file management utilities that support other software
2. **Application Software** — Stand-alone programs solving specific user needs
3. **Engineering/Scientific Software** — Number-crunching applications for fields like automotive stress analysis, molecular biology, and orbital dynamics
4. **Embedded Software** — Lives inside products like microwave ovens and car dashboards
5. **Product-line Software** — Consumer-focused applications like word processors and database tools
6. **Web Applications** — Network-centric software integrated with remote databases and business systems
7. **AI Software** — Uses non-numerical algorithms for robotics, expert systems, and pattern recognition
8. **Open-Source Software** — Free source code open to the community — both a blessing and a potential challenge

## **Defining Software Engineering**

The IEEE defines software engineering as:

> "The application of a systematic, disciplined, and quantifiable approach to the development, operation, and maintenance of software."

Simply put: it's an engineering discipline concerned with all aspects of software production.

## **Computer Science vs Software Engineering**

- **Computer Science** focuses on theories and fundamentals — the "what" and "why"
- **Software Engineering** deals with practicalities — the "how" of developing and delivering useful software

System engineering encompasses all aspects of computer-based development, including hardware and processes. Software engineering is one part of this larger picture.

## **What Makes Software "Good"?**

Four essential attributes define quality software:

- **Maintainability** — Software must evolve with changing customer needs. In a dynamic business environment, change is inevitable
- **Dependability & Security** — The software should be reliable and safe. System failures shouldn't cause physical or economic damage, and malicious users shouldn't be able to compromise it
- **Efficiency** — Resources like memory and processing power should be used wisely (responsiveness, processing time, memory utilization)
- **Acceptability** — Users must find the software understandable, usable, and compatible with their existing tools

## **Software Engineering as a Layered Technology**

Think of software engineering as four stacked layers:

1. **Quality Focus** — Forms the foundation. Every engineering approach needs organizational commitment to quality and continuous improvement
2. **Process** — Defines the framework for effective delivery. Establishes where products are created, milestones set, quality ensured, and change managed
3. **Methods** — Provide the technical how-to's: communication, requirements analysis, design modeling, construction, testing, and support
4. **Tools** — Offer automated support for processes and methods, making the work more efficient and consistent

## **Software Crisis**

### **What is Software Crisis?**

The software crisis refers to when the complexity of software projects began to exceed the capabilities of existing development methods and tools. When the demand for software outpaces production due to increasing complexity, problems arise.

**The reality:**

- 28% of projects complete on time and within budget
- 49% experience delays or exceed budget
- 23% of projects are cancelled entirely


### **Symptoms and How to Track Them**

1. **Over Budget** — Can be tracked using an S-Curve to find the variance between predicted and actual costs
2. **Schedule Slippage** — Can be tracked with Gantt charts or milestone charts which allocate dates for each production phase
3. **Poor Quality** — Can be tracked using Earned Value Management (EVM), customer satisfaction metrics, and bug tracking

### **Major Causes**

- Communication difficulties between stakeholders and teams
- Management of complexity as systems grow larger
